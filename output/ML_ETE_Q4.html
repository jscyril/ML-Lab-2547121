Machine Learning ETE Question 4¶

Why this combination?¶

  • PCA is an appropriate unsupervised dimensionality-reduction method for continuous, correlated numeric variables. Standardisation is required because PCA is scale-sensitive.
  • Random Forest Regressor is an ensemble of decision trees that models non-linear relationships and feature interactions with little tuning.
  • PCA is fitted inside a Pipeline, so it learns only from the training split and cannot leak test-set information. The baseline shows whether reduction is worthwhile for this small, eight-feature dataset.

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=RANDOM_STATE
)

baseline = RandomForestRegressor(
    n_estimators=200, random_state=RANDOM_STATE, n_jobs=-1
)
pca_preprocessor = Pipeline([
    ('impute', SimpleImputer(strategy='median')),
    ('scale', StandardScaler()),
])
pca_forest = Pipeline([
    ('preprocess', pca_preprocessor),
    ('pca', PCA(n_components=0.95, random_state=RANDOM_STATE)),
    ('forest', RandomForestRegressor(
        n_estimators=200, random_state=RANDOM_STATE, n_jobs=-1
    )),
])

results = []
for name, model, feature_count in [
    ('Random Forest (baseline)', baseline, X_train.shape[1]),
    ('PCA (95%) + Random Forest', pca_forest, None),
]:
    start = time.perf_counter()
    model.fit(X_train, y_train)
    fit_seconds = time.perf_counter() - start
    predictions = model.predict(X_test)
    if feature_count is None:
        feature_count = model.named_steps['pca'].n_components_
    results.append({
        'Model': name,
        'Features used': feature_count,
        'Variance retained': 1.0 if name.startswith('Random') else model.named_steps['pca'].explained_variance_ratio_.sum(),
        'R²': r2_score(y_test, predictions),
        'RMSE': mean_squared_error(y_test, predictions) ** 0.5,
        'Fit time (s)': fit_seconds,
    })

comparison = pd.DataFrame(results).set_index('Model')
assert np.isfinite(comparison[['R²', 'RMSE', 'Fit time (s)']].to_numpy()).all()
display(comparison.round(4))

Discussion¶

  • Accuracy: PCA may improve generalisation when noisy or highly collinear features dominate. It can also lower R² here because principal components preserve feature variance, not their relationship with house price. Use the displayed hold-out R² and RMSE to choose the better model.
  • Computation cost: retaining 95% of variance reduces the number of inputs evaluated at each tree split, which can reduce memory and fitting cost for wide datasets. On this dataset PCA itself adds a small upfront cost and only eight features exist, so the baseline can be just as fast or faster.
  • Interpretability: the baseline's feature importances refer to original variables such as MedInc and AveRooms. PCA features are weighted mixtures of those variables, so the PCA pipeline is less directly interpretable even when accuracy is similar.

Conclusion: keep PCA + Random Forest only if its validation performance is comparable or better and dimensionality reduction is valuable. For these eight original features, the baseline is usually easier to explain.
